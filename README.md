## How to Use

1. Download a copy of [`Flogwrite`](https://github.com/bashberryy/666c6f677772697465/releases/) from Releases.
2. Use [Chromebook Recovery Utility](https://chromewebstore.google.com/detail/chromebook-recovery-utili/pocpnlppkickgojjlmhdmidojbmbodfm?hl=en) to write it to a USB / SD card.
3. On your enrolled Chromebook, press `ESCAPE + REFRESH + POWER ⏻`.
4. Press `CTRL + D`.
5. Once your Chromebook asks to return to secure mode, **DO NOT press `ENTER`**. Instead, press `ESCAPE + REFRESH + POWER ⏻` again.
6. Plug in your loaded USB / SD card.
7. Follow the on-screen steps.
